# План: Единый новогодний стиль интерфейса

## Анализ текущего состояния

Приложение **ChristmasTrees** уже имеет базовую новогоднюю цветовую палитру, но есть проблемы единообразия:

### Найденные проблемы:
1. **Color.kt** — устаревшие Purple/Pink цвета (legacy) не нужны
2. **themes.xml / colors.xml** — стандартные Android цвета без новогодней тематики
3. **Type.kt** — стандартная Material типографика без новогоднего характера
4. **AppNavigation.kt** — навигационный бар не использует тему, хардкод цвета
5. **MapScreen.kt** — множество хардкоженных цветов (`ComposeColor(0xFF1B5E20)` и т.д.) вместо токенов темы
6. **ListScreen.kt** — в целом хороший стиль, но можно усилить новогоднее оформление
7. **MarkerPickerBottomSheet.kt** — цвета не согласованы с темой
8. **Отсутствуют декоративные элементы** — снежинки, градиенты, праздничные тени

---

## Шаг 1: Очистка и обновление Color.kt

**Файл:** `app/src/main/java/com/example/christmastrees/ui/theme/Color.kt`

- Удалить legacy-цвета (Purple80, PurpleGrey80, Pink80, Purple40, PurpleGrey40, Pink40)
- Добавить дополнительные новогодние цвета:
  - `SnowWhite = Color(0xFFFFFAFA)` — для светлых элементов
  - `FrostBlue = Color(0xFFB3E5FC)` — для акцентов
  - `BerryRed = Color(0xFF8E0000)` — для hover/pressed состояний
  - `ForestDark = Color(0xFF0A1F0D)` — для глубокого тёмного фона
- Добавить ColorTokens для состояний (pressed, hovered)


**Файл:** `app/src/main/res/values/themes.xml`

- Добавить holiday-стиль для ActionBar:
  ```xml

      <item name="android:statusBarColor">@color/purple_700</item>
      <item name="android:navigationBarColor">@color/purple_700</item>
  </style>
  ```

## Верификация

1. **Сборка:** `./gradlew assembleDebug` — без ошибок компиляции
2. **Lint:** `./gradlew lintDebug` — без предупреждений о стилях
3. **Ручная проверка:**
   - Все экраны используют единую палитру (зелёный/красный/золотой)
   - Нет хардкоженных цветов в UI-коде
   - Навигационный бар стилизован
   - Карточки, кнопки, диалоги — единый стиль
   - Типографика согласована
   - Декоративные элементы (снежинки) не мешают UX
