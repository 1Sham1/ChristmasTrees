## Шаг 6: Метод в ViewModel для изменения размера

**Файл**: `app/src/main/java/com/example/christmastrees/viewmodel/MarkersViewModel.kt`

```kotlin
fun updateMarkerSize(markerId: String, newSize: MarkerSize) {
    val markers = _uiState.markers.toMutableList()
    val index = markers.indexOfFirst { it.id == markerId }
    if (index >= 0) {
        markers[index] = markers[index].copy(size = newSize)
        _uiState.value = _uiState.value.copy(markers = markers)
        saveMarkersToPrefs(markers)
        syncUiState()
    }
}
```
