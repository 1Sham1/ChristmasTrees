# Экспорт и импорт профилей

## Цель
Добавить кнопки "Экспорт" и "Импорт" в экран управления профилями для сохранения/загрузки профилей в JSON-файл на внешнее хранилище устройства.

## Формат экспорта (JSON)
```json
{
  "version": 1,
  "exportedProfile": "ProfileName",
  "markers": [...],
  "musicEnabled": true,
  "snowEnabled": true,
  "mapLat": 55.7558,
  "mapLon": 37.6173,
  "mapZoom": 14.0
}
```

## Шаги реализации

### 1. Создать data класс ExportProfile (новый файл)
- `ExportProfile` — data class для сериализации всех данных профиля
- Поля: version, exportedProfile, markers (List<Marker>), musicEnabled, snowEnabled, mapLat, mapLon, mapZoom
- Расположить в `data/ExportProfile.kt`

### 2. Добавить методы exportProfile и importProfile в ProfileManager
- `exportProfile(context, profileName, fileUri)`:
  - Собрать markers из SharedPreferences через MarkersViewModel логику
  - Собрать settings из SettingsManager
  - Собрать map position из SettingsManager
  - Создать ExportProfile объект
  - Сериализовать в JSON через Gson
  - Записать в файл по URI через OutputStream
- `importProfile(context, fileUri, targetProfileName)`:
  - Прочитать JSON из файла по URI
  - Десериализовать в ExportProfile
  - Записать markers в SharedPreferences
  - Записать settings в SharedPreferences
  - Записать map position в SharedPreferences

### 3. Добавить кнопки в ProfileManagementScreen
- В TopAppBar добавить кнопку "Экспорт" (иконка share/download)
- В TopAppBar добавить кнопку "Импорт" (иконка upload)
- При нажатии "Экспорт" — показать AlertDialog с выбором профиля для экспорта (если профиль не один)
- При нажатии "Импорт" — показать AlertDialog с подтверждением и выбором имени целевого профиля

### 4. Добавить Activity Result API для SAF (Storage Access Framework)
- ИспольActivityResultContracts.CreateDocument для экспорта (выбор файла для сохранения)
- ИспольActivityResultContracts.GetContent для импорта (выбор файла для открытия)
- MIME type: "application/json"

### 5. Обновить AppNavigation.kt
- Передать callbacks exportProfile и importProfile в ProfileManagementScreen
- Обработать результаты Activity Result

### 6. Добавить строки ресурсов
- strings.xml: "Экспорт профиля", "Импорт профиля", "Сохранить файл", "Выберите файл", и т.д.

## Детали реализации

### Permissions
- Для Android 13+ (API 33+) — READ_MEDIA_IMAGES не нужен для JSON, SAF работает без разрешений
- Для Android 12- (API < 33) — может потребоваться WRITE_EXTERNAL_STORAGE для общих директорий
- SAF (Storage Access Framework) работает без разрешений через системный диалог выбора файла

### UI Flow
1. **Экспорт:**
   - Пользователь нажимает "Экспорт" в TopAppBar
   - Если профиль один — сразу показывается диалог выбора файла (CreateDocument)
   - Если профилей несколько — сначала выбор профиля из списка
   - Файл сохраняется как `{profileName}_profile.json`

2. **Импорт:**
   - Пользователь нажимает "Импорт" в TopAppBar
   - Открывается системный диалог выбора файла (GetContent)
   - После выбора — диалог подтверждения с выбором целевого профиля
   - Данные загружаются в выбранный профиль

### Обработка ошибок
- Показывать Snackbar/AlertDialog при ошибках чтения/записи
- Валидация JSON структуры при импорте
- Проверка версии формата экспорта
