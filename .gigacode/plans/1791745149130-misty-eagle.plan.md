# План создания иконки приложения "Christmas Trees vs Zombies"

## Контекст
- **Проект:** Android приложение "Christmas Trees" (mapping app с osmdroid + Jetpack Compose)
- **Текущая иконка:** Стандартная Android Studio (зелёный робот Android)
- **Пакет:** `com.example.christmastrees`
- **Цветовая палитра:** Уже определена в `res/values/colors.xml` (christmas_green, christmas_red, christmas_gold, forest_dark, snow_white, frost_blue)

## Цель
Создать кастомную иконку приложения, на которой ёлки сражаются с зомби и нечистью.

## Подход
Используем **Vector Drawable** (XML) — масштабируется без потери качества, нативно поддерживается Android, легко редактируется.

## Архитектура иконки

### Композиция (сверху вниз):
1. **Фон:** Ночное зимнее небо (тёмно-синий/фиолетовый градиент)
2. **Луна:** Полумесяц в углу
3. **Звёзды:** Мелкие точки
4. **Передний план — Земля:** Снежный покров (белый/светло-голубой)
5. **Ёлки-воины (левая сторона):**
   - 2-3 ёлки с мечами/щитами
   - Ёлки имеют "лица" (глаза, решительные брови)
   - Украшены как рождественские, но в боевой стойке
6. **Зомби и нечисть (правая сторона):**
   - 1-2 зомби (серо-зелёные, с поднятыми руками)
   - Летучая мышь или летучий демон
   - Призрак или скелет
7. **Эффекты битвы:** Искры/вспышки в центре

## Цвета (из colors.xml)
- Фон: `frost_blue` / `christmas_dark` (ночное небо)
- Снег: `snow_white`
- Ёлки: `christmas_green`, `christmas_green_dark`
- Лица ёлок: `snow_white` (глаза), `christmas_red` (зрачки)
- Зомби: `forest_dark`, тёмно-зелёный
- Луна: `christmas_gold`
- Украшения ёлок: `christmas_red`, `christmas_gold`
- Нечисть: `christmas_dark`, серый

## Файлы для изменения

### 1. `app/src/main/res/drawable/ic_launcher_background.xml`
**Статус:** Полностью заменить
**Описание:** Vector drawable с градиентом ночного неба, луной и звёздами.
- Viewport: 108x108dp
- Градиент от `christmas_dark` (верх) к `frost_blue` (низ)
- Полумесяц в правом верхнем углу (`christmas_gold`)
- 5-7 звёзд-точек

### 2. `app/src/main/res/drawable/ic_launcher_foreground.xml`
**Статус:** Полностью заменить
**Описание:** Vector drawable с ёлками-воинами и зомби.
- Viewport: 108x108dp
- Снежный покров внизу (y=75...108)
- Ёлки-воины слева (x=10...40)
- Зомби и нечисть справа (x=60...95)
- Эффекты битвы в центре (x=40...60)

**Детали ёлок:**
- Ёлка 1 (большая, центр-лево): треугольная крона из 3 ярусов, ствол коричневый, меч в правой "ветке"
- Ёлка 2 (поменьше, левее): щит в "ветке", рождественские шары (красные/золотые)
- Лица: белые овалы-глаза с красными зрачками

**Детали зомби:**
- Зомби 1: серо-зелёное тело-прямоугольник, круглая голова, серые руки подняты вверх
- Зомби 2 (поменьше, ниже): пригнувшийся, с оскалом
- Летучая мышь (верх-право): чёрный силуэт с расправленными крыльями
- Призрак (центр-право): белый полупрозрачный силуэт с глазами

### 3. `app/src/main/res/mipmap-anydpi/ic_launcher.xml`
**Статус:** Проверить (должна ссылаться на новые drawable)
```xml
<adaptive-icon xmlns:android="http://schemas.android.com/apk/res/android">
    <background android:drawable="@drawable/ic_launcher_background" />
    <foreground android:drawable="@drawable/ic_launcher_foreground" />
    <monochrome android:drawable="@drawable/ic_launcher_foreground" />
</adaptive-icon>
```

### 4. `app/src/main/res/mipmap-anydpi/ic_launcher_round.xml`
**Статус:** Проверить (такая же структура, круглая маска)

## Реализация Vector Drawable

Каждый vector drawable будет содержать:
- `<vector>` корневой элемент с viewportWidth="108" viewportHeight="108"
- `<group>` для трансформаций (если нужно)
- `<path>` для каждой фигуры (ёлка, зомби, луна, звёзды)
- `<path>` с градиентами для фона
- `<path>` с fillAlpha для полупрозрачных элементов (призрак)

## Порядок выполнения

1. **Создать `ic_launcher_background.xml`** — ночное небо + луна + звёзды
2. **Создать `ic_launcher_foreground.xml`** — ёлки-воины + зомби + нечисть
3. **Проверить `ic_launcher.xml` и `ic_launcher_round.xml`** — убедиться в ссылках
4. **Собрать проект** — убедиться в отсутствии ошибок компиляции
5. **Проверить в превью Android Studio** — убедиться что иконка отображается корректно

## Верификация
- `./gradlew assembleDebug` — сборка без ошибок
- Открыть `ic_launcher_background.xml` и `ic_launcher_foreground.xml` в Android Studio Layout Inspector
- Запустить эмулятор и проверить иконку на главном экране
- Проверить обе версии: квадратную и круглую иконку

## Примечания
- Все размеры в dp (viewport 108x108 — стандарт Android adaptive icon)
- Safe region для foreground: центр 66x66dp (остальное может быть обрезано)
- Monochrome drawable — для тёмной темы (используем foreground как monochrome)
- Стиль: flat design с минимальными тенями, подходящий для иконки приложения
