# План: Редактирование имени и количества маркера в контекстном меню

## Задача
При нажатии на маркер в контекстном меню добавить:
1. **Редактируемое имя** — текстовое поле, по умолчанию заполненное названием типа маркера (например "Ёлка", "Снеговик", "Украшения")
2. **Редактируемый счётчик** — возможность вписать точное число вместо кнопок +1/-1

## Изменяемые файлы

### 1. `app/src/main/java/com/example/christmastrees/viewmodel/MarkersViewModel.kt`
- **Добавить поле `name`** в data class `Marker`:
  ```kotlin
  data class Marker(
      val id: Long,
      val latitude: Double,
      val longitude: Double,
      val type: String,
      val name: String,        // NEW: custom name, defaults to marker type label
      val timestamp: Long,
      val quantity: Int = 1
  ) {
      fun markerType(): MarkerType = MarkerType.fromString(type)
  }
  ```
- **Добавить метод `updateMarkerName`** для обновления имени:
  ```kotlin
  fun updateMarkerName(markerId: Long, newName: String) {
      val newList = markers.toMutableList()
      val idx = newList.indexOfFirst { it.id == markerId }
      if (idx != -1) {
          newList[idx] = newList[idx].copy(name = newName)
      }
      markers = newList
      saveMarkers()
  }
  ```
- **Обновить `placeMarker`** — устанавливать `name` по умолчанию из `type.label`:
  ```kotlin
  val newMarker = Marker(
      id = nextId++,
      latitude = latitude,
      longitude = longitude,
      type = type.name,
      name = type.label,  // NEW: default name from type
      timestamp = System.currentTimeMillis(),
      quantity = 1
  )
  ```
- **Обновить `loadMarkersFromStorage`** — читать/создавать поле `name` с дефолтом:
  ```kotlin
  val name = prefs.getString("marker_$i.name", null) ?: MarkerType.fromString(type).label
  ```
- **Обновить `saveMarkers`** — сохранять поле `name`.

### 2. `app/src/main/java/com/example/christmastrees/ui/screens/MapScreen.kt`
- **Обновить создание маркеров** в `LaunchedEffect(markers)` и `LaunchedEffect(Unit)` — передавать `name` при создании `Marker` (если поле ещё не заполнено, использовать `type.label`).
- **Заменить контекстное меню** — обновить секцию `if (showContextMenu && selectedMarkerId != null)`:
  - Добавить `TextField` для имени маркера (`value = customName`, `onValueChange = { customName = it }`)
  - Добавить `TextField` для количества (`value = customQuantity`, `onValueChange = { customQuantity = it.toIntOrNull() }`)
  - Сохранение изменений по потере фокуса (`onFocusLost`) или по кнопке
  - Оставить кнопки +1/-1 как дополнительные (опционально)

  Пример структуры контекстного меню:
  ```
  [Emoji]
  [TextField: имя маркера (редактируемое)]
  Количество: [TextField: число]  [+][-]
  [Переместить]
  [Удалить]
  ```

## Неизменяемые файлы
- `MarkerType.kt` — enum не меняется
- Остальные экраны и навигация

## Верификация
1. Создать новый маркер → в контекстном меню отображается имя по типу ("Ёлка")
2. Изменить имя в текстовом поле → сохранить → при повторном открытии меню новое имя отображается
3. Изменить количество через текстовое поле → значение сохраняется
4. Кнопки +1/-1 продолжают работать
5. Существующие маркеры (без имени) получают имя по умолчанию из типа
