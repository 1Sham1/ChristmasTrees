# План: Система профилей в приложении Christmas Trees

## Контекст

Текущее приложение хранит **все данные** (маркеры, настройки музыки/снега, позицию карты) в трёх файлах SharedPreferences:
- `markers_data` — маркеры
- `app_settings` — музыка/снег
- `map_settings` — позиция карты

**Нет** Room/DataStore/DI. Всё пишется напрямую в SharedPreferences из MarkersViewModel и SettingsManager.

## Требования

1. В SettingsDialog добавить пункт «Профили»
2. При нажатии открывается экран управления профилями
3. Возможности: **создать**, **удалить**, **переименовать**, **переключиться**
4. Каждый профиль хранит **полный набор данных**: маркеры + настройки + позиция карты
5. При переключении профиля — данные подгружаются из него, новые данные сохраняются в активный профиль
6. По умолчанию — один профиль «Default» (нельзя удалить)

## Архитектурное решение

Используем **SharedPreferences с префиксами**, без перехода на DataStore (чтобы сохранить текущую архитектуру):

- `profiles_data` — список профилей (имена + id активного)
- `markers_data_{profileName}` — маркеры конкретного профиля
- `app_settings_{profileName}` — настройки конкретного профиля
- `map_settings_{profileName}` — позиция карты конкретного профиля

Активный профиль хранится в **общем** SharedPreferences `app_settings` (ключ `active_profile`).

## Детальный план по шагам

### Шаг 1: Создать `ProfileManager.kt`
**Файл:** `app/src/main/java/com/example/christmastrees/util/ProfileManager.kt`

Новый объект-менеджер для управления профилями:

```kotlin
object ProfileManager {
    // Константы
    private const val PROFILES_PREFS = "profiles_data"
    private const val KEY_PROFILES = "profiles"         // JSON: список имён ["Default", ...]
    private const val KEY_ACTIVE_PROFILE = "active_profile" // имя текущего профиля
    
    // Методы:
    fun init(context: Context)           // создаёт профиль "Default" если пуст
    fun getProfileNames(context: Context): List<String>
    fun getActiveProfile(context: Context): String
    fun setActiveProfile(context: Context, name: String)
    fun createProfile(context: Context, name: String): Boolean  // true если успешно
    fun deleteProfile(context: Context, name: String): Boolean  // false если "Default"
    fun renameProfile(context: Context, oldName: String, newName: String): Boolean
    fun migrateDataToProfile(context: Context, profileName: String)  // переносит данные из дефолтных файлов в профиль
}
```

**Детали реализации:**
- Список профилей храним как JSON-строку (используем уже подключённый Gson)
- `init()` проверяет, есть ли профили; если нет — создаёт ["Default"] и мигрирует существующие данные
- `getProfileNames()` возвращает список, `setActiveProfile()` сохраняет имя
- `createProfile()` проверяет уникальность имени, добавляет в список
- `deleteProfile()` удаляет из списка + удаляет все SharedPreferences файлы профиля
- `renameProfile()` переименовывает в списке + переименовывает все SharedPreferences файлы

## Миграция существующих данных

При первом запуске после добавления (в `ProfileManager.init`):
1. Проверить, есть ли данные в `markers_data`, `app_settings`, `map_settings`
2. Если есть — перенести в профиль «Default» (в `markers_data_Default`, `app_settings_Default`, `map_settings_Default`)
3. Удалить старые файлы (или оставить как fallback)

## Верификация

1. **Сборка:** `./gradlew assembleDebug` — без ошибок
2. **Создание профиля:** Settings → Профили → + → ввести имя → профиль создан
3. **Переименование:** Долгое нажатие → «Переименовать» → новое имя → профиль переименован
4. **Удаление:** Долгое нажатие → «Удалить» → подтверждение → профиль удалён (Default нельзя)
5. **Переключение:** Клик по профилю → данные приложения подгрузились из профиля
6. **Изоляция данных:** Создать профиль A → поставить маркеры → переключиться на Default → маркеры A отсутствуют → переключиться на A → маркеры вернулись
7. **Настройки:** Включить музыку в профиле A → переключиться на Default → музыка выключена → переключиться на A → музыка включена
8. **Позиция карты:** Переместить карту → переключить профиль → вернуться → карта в исходной позиции
